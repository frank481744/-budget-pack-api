# BUDGET PACK API

Projet Cloudflare Worker pour le Worker existant `budget-pack-api`.

- `worker.js` : code de l'API
- `wrangler.jsonc` : configuration du Worker
- `package.json` : Wrangler
- `schema.sql` : référence des tables D1

Après le premier déploiement depuis GitHub, vérifier le binding D1 `DB -> budget-pack` dans Cloudflare.
